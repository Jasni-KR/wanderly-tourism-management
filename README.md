# Wanderly Tourism Management Website

A web-based tourism management system developed using Django. This project allows users to explore destinations and book hotel reservations through an easy-to-use interface.

## 🔗 Live Demo
https://wanderly-tourism-management.onrender.com

## 💻 GitHub Repository
https://github.com/Jasni-KR/wanderly-tourism-management

## 🚀 Features
- View tourism destinations and services
- Hotel listing and reservation system
- User-friendly booking form
- Admin panel to manage bookings and data

## 🛠️ Technologies Used
- Python (Django)
- HTML, CSS
- SQLite

## 📌 How to Run Locally
1. Clone the repository  
2. Install dependencies  
   pip install -r requirements.txt
3. Run the server
   python manage.py runserver
4. Open in browser
   http://127.0.0.1:8000
